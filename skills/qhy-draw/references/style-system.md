# qhy-draw 风格系统

`qhy-draw` 的风格不只是配色，而是背景、字体气质、边框、箭头、容器标题、留白密度的一整套表达规则。

如果用户没有指定风格，先选图型，再选风格，不要反过来。

## 风格 1：扁平图标风

适合：

- 通用文档
- 博客配图
- 产品说明
- 不需要强烈品牌感的正式图

特征：

- 白底
- 中性色容器 + 少量强调色
- 边框清楚，阴影很轻
- 适合架构图、数据流图、对比图

## 风格 2：暗色终端风

适合：

- 开发者内容
- CLI / Tool Call / Agent Loop
- 深色技术文章

特征：

- 深色背景
- 高对比箭头与描边
- 可用等宽字体气质
- 局部可出现终端标题栏、状态信息

注意：

- 不要为了“炫”把霓虹效果拉太满
- 文字必须保证足够亮度和对比度

## 风格 3：蓝图工程风

适合：

- 微服务架构
- 云基础设施
- 系统蓝图
- 有工程说明、编号分区的图

特征：

- 深蓝背景或浅蓝工程底
- 网格感、编号区块、工程标题框
- 线条多于色块，强调结构秩序

## 风格 4：Notion 极简风

适合：

- 内部文档
- Wiki
- 培训资料
- 需要克制、清楚、长期维护的图

特征：

- 白底
- 低饱和灰边
- 单一强调色
- 强调标签与分组，而不是视觉特效

## 风格 5：玻璃拟态风

适合：

- 产品发布
- 面向外部展示
- 多 Agent 协作图
- 需要“未来感”但仍可读的图

特征：

- 渐变暗底
- 半透明卡片
- 少量高光与柔和阴影
- 用卡片层次代替复杂边框

注意：

- 不要牺牲清晰度
- 节点太多时不要硬上玻璃拟态

## 风格 6：Claude 风

适合：

- 温暖、克制、偏叙述型的系统图
- 需要柔和背景和品牌感但不想太商业化

特征：

- 温暖浅底
- 低饱和强调色
- 左侧层级标签、右下角图例都很合适

## 风格 7：OpenAI 风

适合：

- 现代、干净、极简的 API / 模型 / 工具图
- 对外文档和产品说明

特征：

- 纯净白底
- 精确留白
- 少量绿色或中性色强调
- 形状和对齐必须很干净

## 风格选择建议

- 流程图：优先扁平图标风、Notion 极简风、暗色终端风
- 架构图：优先扁平图标风、蓝图工程风、Claude 风
- 时序图：优先暗色终端风、Notion 极简风
- 对比图：优先 Notion 极简风、扁平图标风
- Agent / Memory 图：优先暗色终端风、玻璃拟态风、蓝图工程风

## 风格使用规则

- Mermaid 输出不强求完全复刻这些风格，但应沿用布局和分组思路
- SVG 输出必须选一个主风格，不要混搭两套审美
- 没有用户要求时，默认不要上重阴影、强发光、复杂渐变
