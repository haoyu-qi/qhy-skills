# 信息图 (Infographic Card)

将复杂信息转化为专业级 HTML 信息卡片的 Claude 技能。

## 支持的视觉风格

| 风格 | 适用场景 | 关键特征 |
|------|----------|----------|
| **暗黑科技风** | 产品资料、功能列表、版本日志 | 深色背景、悬浮辉光卡片、背景水印编号 |
| **扁平现代风** | AI 产品宣传、技术指标展示 | 浅色背景、多彩卡片、大背景数字/百分比 |
| **杂志质感风** | 社Editorial风格内容、深度报道 | 18-20px 正文、噪点纹理、重型分割线 |
| **复古书卷风** | 书籍内容解析、文学内容 | 中国传统配色、装饰纹样、书法字体 |
| **蓝图波普风** | 高密度干货、技术教程 | 实验室精密感、波普色彩、坐标系统 |
| **纯白演示风** | 季度版本更新、演示文稿 | 16:9 分页、纯白背景、高对比高亮 |
| **周报模块风** | 工作周报、数据看板 | 彩色分区（蓝/绿/黄/红）、模块化布局 |

## 安装

1. 下载 `infographic-card.skill` 文件
2. 将文件放入 Claude 的 skills 目录
3. 重启 Claude 或重新加载技能

## 使用方式

```
生成一张信息图展示 XXX
一图看懂 XXX
帮我生成周报 HTML
把这本书的内容做成信息卡片
```

## 输出格式

- **HTML 单文件**（内联 CSS）
- **JSON 结构化数据**（可选）

## 技能结构

```
infographic-card/
├── SKILL.md              # 主文件
└── references/
    ├── dark-tech.md      # 暗黑科技风
    ├── flat-modern.md    # 扁平现代风
    ├── magazine.md       # 杂志质感风
    ├── vintage-book.md   # 复古书卷风
    ├── blueprint-pop.md  # 蓝图波普风
    ├── white-presentation.md  # 纯白演示风
    └── weekly-report.md  # 周报模块风
```

## 示例输出

### 暗黑科技风
```html
<!-- 深色背景 #101116 -->
<!-- 悬浮辉光卡片 #1F232B -->
<!-- 背景水印编号 01, 02, 03... -->
```

### 周报模块风
```html
<!-- 淡蓝区块：核心摘要 -->
<!-- 淡绿区块：研发详情 -->
<!-- 淡黄区块：下周计划 -->
<!-- 淡红区块：风险与关注项 -->
```
