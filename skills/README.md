# Skills Directory

这里存放 `qhy-skills` 仓库中的所有技能。

## 当前技能

- `qhy-card`：HTML 视觉卡片生成

## 新增技能建议

1. 复制 `skills/_template/`
2. 将目录重命名为 `skills/qhy-<name>/`
3. 修改 `SKILL.md`
4. 按需补充 `references/`、`assets/`、`scripts/`
5. 更新仓库根目录 `README.md` 中的技能总览

## 命名约定

- 统一使用 `qhy-*`
- 技能名尽量表达能力，而不是表达实现方式
- 避免一个技能承担过多互不相关的职责
