# 诊断与改写

“审阅/体检”交诊断；“去 AI 味/清理”做保真最小编辑；“重写/结构重组”可改篇章；“精简”删重复但保留实质内容。用户明确要完整修订时直接交全文，不停在示例。

缺支撑可以指出，不自动新增主张、数字、第一人称和动机。

## 四层诊断顺序

1. **可信度**：来源、口径、限定与结论匹配吗？有无把相关说成因果、假设说成实测？
2. **逻辑**：主问题有答案吗？标准一致吗？依据能支撑判断吗？案例位置合适吗？
3. **表达**：所指、条件、因果清楚吗？重复、套话、定语有无妨碍理解？
4. **口播**：实际朗读是否卡嘴，换气自然吗，关键数字和术语听得懂吗？

复杂旧稿先概括逻辑链，再找最影响理解的 1—2 个问题。其他实质问题也需处理，不为固定数量隐藏错误。

每个问题给位置、原句或原顺序、影响和可用修改。结构用“现有顺序 → 建议顺序”，句子用“原句 → 建议句”。没问题就保留，不凑问题。

清理任务发现逻辑问题时可单独建议，正文仍按授权范围修改；明确重写才移章节、删整段或新增论证。

## 文本扫描

`scripts/text_review.py` 可定位空泛词、空转开头、强断言、反转句、引导套话和口播较长分句。返回原文位置及语境；正常术语或引文也可能命中。

- 命中不等于错误，未命中不代表逻辑正确。
- 不输出 AI 生成概率、人味分数或通过率，不设必过阈值。
- 不为减少命中数删专业词、必要标点或作者习惯。
- 数字、人称、设问和连接词不作达标配额。
- Markdown、代码和引文也会被扫描；受保护区域保留，只编辑授权正文。

无 Python 时按风格表人工定位。用户没要检测报告就交净稿，不附全部命中。

## 修订验收

核对姓名、数值、时间、主体、否定、条件、归因及强度，尤其检查：

- “可能/通常/据材料/测试中”有无被删除。
- 新句有无增加收益承诺、因果或亲历。
- 衔接是否清楚，有无删到需要读者猜关系。
- 最小清理是否保持章节及段落位置，没问题的文字有无保留。
- 每个改动能否解释必要性；不能的还原。

引文不凭印象改。关键事实缺失时给简短缺口说明，不伪装完成；用户要净稿时只交净稿。
