# qhy-draw 输出规格

## 默认优先级

如果用户没有指定格式，默认先给：

1. 图标题
2. 图的结构说明
3. Mermaid 或白板布局草稿

只有当用户明确需要可交付图时，才默认输出完整 SVG。

## Mermaid 优先场景

- 用户需要快速复制使用
- 更重结构，不重视觉装饰
- 适合流程图、简单架构图、关系图
- 图仍处于讨论阶段

输出建议包含：

- 图标题
- 一段结构说明
- 可直接使用的 Mermaid

## SVG 优先场景

- 用户明确要求 SVG
- 图要用于文档、演示、报告或对外展示
- Mermaid 已经不足以表达层次和语义
- 需要图例、语义箭头、容器分区、品牌化风格

输出建议包含：

- 图标题
- 布局说明
- 完整 SVG
- 图例说明

## 白板草案优先场景

- 用户仍在讨论阶段
- 需要保留“先搭结构再细化”的状态
- 信息还不足以直接出定稿

输出时建议包含：

- 图标题
- 布局说明
- 模块分区
- 节点清单
- 连接关系

## SVG 结构要求

- 必须有清晰标题
- 必须有统一的容器和节点风格
- 箭头类型超过 2 种时必须有图例
- 文字标签要短，说明性文字放到副标题、图例或注释区
- 尽量复用 `assets/svg_canvas_template.svg` 的画布和图例思路

## 交付表达建议

- 如果信息还不稳定，明确标注为“草案”
- 如果已有确定结论，直接输出可交付稿
- 如果一张图无法同时承担“解释结构”和“解释流程”，优先给拆图建议
