# 模具：信息图

## 目标

把复杂内容压缩成一页可读、可分享、可快速扫描的 HTML 信息图。

## 方法

### 1. 先判断三件事

- 密度：稀 / 中 / 密
- 结构：单点 / 对比 / 层级 / 流程 / 辐射 / 并列
- 锚点：哪一个词、数字、结论或关系是画面最大元素

### 2. 选择布局方向

- 单点：一个超级标题或一个超级数字统治画面
- 对比：左右或上下对照，但不要 50/50 死板平分
- 层级：阶梯、塔形、嵌套盒组
- 流程：路径、时间轴、箭头链路
- 辐射：中心节点外扩
- 并列：非对称网格或错落区块

### 3. 字号建议

- 主锚点：80px 到 220px
- 主标题：44px 到 72px
- 副标题：24px 到 32px
- 正文：16px 到 20px
- 标注：13px 到 15px

### 4. 模板使用

读取 `assets/infograph_template.html`，将模板视为画布和底层约束，不要把它当固定布局。

## 避坑

- 不要默认头图居中加三栏卡片
- 不要每张卡都一样高一样重
- 不要把所有信息都做成 bullet list
