# QHY 文章正文配图

把中文正文的关键判断、转折、流程和隐喻变成一秒内能读懂的画面。默认是彩色手绘动画场景；只有用户明确点名时才启用个人 IP、实物涂鸦或 CRT 扩展模式。

## 视觉模式路由

1. **彩色手绘动画 / Default**：16:9 横版，普通人物承担核心动作，彩铅轮廓+水彩/水粉色块+3–5 个短中文标注。
2. **个人 IP 萌粒插画 / Personal IP**：建立可复用角色锚点、转面图和系列一致性；用小角色、大白场、断续手绘线和轻微套色错位表达文章场景。
3. **实物微型人涂鸦 / Object Doodle**：将一个实拍物件作为锚点，用原始黑线小人进行一个与段落含义直接相关的动作。
4. **复古 CRT 叙事 / CRT Narrative**：将人物、物件或抽象主题重构为限色像素编辑插画，用早期计算机窗口和 CRT 信号表面组织信息。
5. **3:4 IP 信息图 / IP Infographic**：用户明确要求知识卡、数据卡、流程、时间线或文章总结海报时使用；个人 IP 只负责引导理解，不挤压信息。

使用第 2–5 种模式前读取 `references/style-modes.md`。若主任务是将一张照片做成独立海报、zine、照片复活或照片抽象编辑，改用 `qhy-photo`。

## 按需读取参考

- 默认模式开始设计或生成前，读取 `references/style-dna.md`。
- 默认模式选择构图和原创隐喻时，读取 `references/composition-patterns.md`。
- 默认模式调用图像生成工具前，读取 `references/prompt-template.md`。
- 所有模式出图后，读取 `references/qa-checklist.md` 并逐张检查。
- 仅在需要校准默认模式的色彩、材质和系列感时查看 `assets/examples/`；不照抄示例构图。

## 统一工作流

### 1. 消化正文

提炼文章的核心观点、认知转折和适合视觉化的段落。不平均配图，优先选择：

- 核心判断或反常识结论。
- 两个概念的分工、冲突或互补。
- 输入、加工、输出或能力升级。
- 前后对比、状态变化、路径与断点。
- 文章结尾最值得记住的判断。

默认长文 4–8 张，短文 1–3 张；不轻易超过 9 张。个人 IP 稀疏正文插画默认 5 张，信息图按信息模块数自动拆页。

### 2. 决定策略与直接生成

- 只要求分析配图位置或方案：先输出 shot list。
- 明确要求生成、输出或做图：直接设计并逐张调用内置图像生成，不等待二次确认。

Shot list 每张写清：放置位置、主题、核心意思、叙事动作、主要元素、建议中文标注。

### 3. 设计单张场景

每张只讲一个核心关系。默认模式让普通人物、拟人工具或操作者承担组装、搬运、调节、拆包、称量、连接、翻译、修补、筛选或验收等动作。若去掉人物后画面仍完全成立，重写场景。

个人 IP 模式不强行套用水彩动画风；优先保持角色锚点、稀疏白场和断续笔触。CRT 模式不使用圆润萌系角色，必须是独立重构的成人像素编辑形象。

### 4. 逐张生成

每张独立调用一次内置图像生成，不把多张图拼成一张。同一批次固定调色板、线条、角色锚点、道具复杂度和文字规则，但改变动作、构图与情绪。

默认模式提示词明确：

- 16:9 横版中文正文配图。
- 彩铅轮廓与水彩/水粉色块。
- 普通人物或成熟动画角色承担核心动作。
- 3–5 个简短、逐字指定的中文标注。
- 禁止小黑、黑色怪物 IP、黑白极简、PPT、正式流程图和商业矢量风。

### 5. 检查与迭代

按 `references/qa-checklist.md` 检查比例、风格、动作、文字和构图，并追加模式专用检查：

- 个人 IP：发型、脸部、轮廓、招牌色和识别配件是否稳定；断续轮廓和轻微套色错位是否真正可见。
- 实物涂鸦：真实物件是否仍是主锚点；小人是否通过动作而非装饰来说明内容。
- CRT：主体是否被重构而非滤镜化；像素网格、调色板、窗口层级、扫描线和边缘弯曲是否一致。
- 信息图：标题、数据、日期、单位、人名和标签是否来自锁定文本；是否为了塞入内容而缩小字号。

中文出现明显错字时，优先减少标注后局部编辑或重生成；不用更多文字补救。

### 6. 保存交付

项目内图片保存到 `assets/<article-slug>-illustrations/`，按文章顺序命名为 `01-topic-name.png`、`02-topic-name.png`。保留原始生成文件；替换时使用 `-v2` 等版本名，除非用户明确要求覆盖。

## 交付口径

说明生成数量、每张用途、尺寸、保存路径、最稳妥的主图和可选图。简要给出共同视觉约束，不长篇解释风格理论。

## 来源与边界

扩展模式对 `ip_illustration_for_yourself`、`heytea-style` 和 `tait-crt-interface-skill` 的公开方法进行独立重构；不复制上游固定签名、品牌 Logo、官方包装、私有参考图、上游原文案或角色身份。`ip_illustration_for_yourself`、`heytea-style` 和 `tait-crt-interface-skill` 的公开页面未标注标准开源许可证；公开发布、客户项目、收费生成、商业服务或二次分发时，使用独立创建的角色和视觉资产，并核对原仓库当前条款。
