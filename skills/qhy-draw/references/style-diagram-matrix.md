# qhy-draw 风格与图型匹配矩阵

不是所有风格都适合所有图型。优先用这个矩阵做默认判断。

| 图型 | 最推荐 | 可用 | 谨慎使用 |
|---|---|---|---|
| 架构图 | 1 扁平图标风、3 蓝图工程风 | 4 Notion、6 Claude、7 OpenAI | 5 玻璃拟态风 |
| 数据流图 | 1 扁平图标风、2 暗色终端风、3 蓝图工程风 | 4 Notion、7 OpenAI | 5 玻璃拟态风 |
| 流程图 | 1 扁平图标风 | 2 暗色终端风、4 Notion、6 Claude、7 OpenAI | 5 玻璃拟态风 |
| 时序图 | 3 蓝图工程风、4 Notion、7 OpenAI | 2 暗色终端风、6 Claude | 5 玻璃拟态风 |
| 对比矩阵 | 4 Notion、7 OpenAI、1 扁平图标风 | 6 Claude | 5 玻璃拟态风、3 蓝图工程风 |
| 时间线 | 1 扁平图标风、4 Notion | 2 暗色终端风、6 Claude、7 OpenAI | 5 玻璃拟态风 |
| UML / ER | 3 蓝图工程风、4 Notion、7 OpenAI | 1 扁平图标风、6 Claude | 5 玻璃拟态风 |
| Agent / Memory | 2 暗色终端风、5 玻璃拟态风、6 Claude | 1 扁平图标风、3 蓝图工程风、7 OpenAI | 无 |

默认规则：

- 结构型图优先清晰，不优先炫技
- 表格、矩阵、UML 图优先极简和工程风
- Agent / AI 图更适合深色技术风或展示风
