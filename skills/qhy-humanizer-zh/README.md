# qhy-humanizer-zh（qhy-human）

中文去 AI 味与文字编辑技能。默认少改、保留作者口吻、事实和文章结构；用户明确要求润色、精简或重写时按该范围处理。

可直接提出：“用 qhy-human 去掉这段文字的 AI 味，保留我的语气。”技能正式名称仍为 `qhy-humanizer-zh`，不用迁移既有调用。

主要能力：中文结构的 11 类检查、段落回指与五类翻译腔修复、宣传腔与交互残留清理，以及逐处信息保真验收。句长、三项列举、普通比喻或某个词语不会单独触发改写。

例如，“单次耗时明显改善，从 2 小时缩短到 40 分钟”可改为“单次耗时从 2 小时缩短到 40 分钟”。不会添加原文不存在的功能、反馈或经历；“可能”“通常”等限定保留。
