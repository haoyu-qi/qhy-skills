# qhy-draw SVG 布局最佳实践

## 1. 先布局，再写细节

- 先确定画布尺寸
- 先放容器和主节点
- 再补标签和箭头
- 最后再处理图例与装饰

## 2. 容器比单点更重要

- 复杂图优先用容器建立分层
- 容器标题应比节点标签更容易扫读
- 不要让所有信息都落在单个节点里

## 3. 箭头必须有语义

- 主数据流、控制流、读、写、异步、反馈应区分
- 不要所有箭头都一样粗、一样色、一样虚实

## 4. 标签应有安全背景

- 箭头标签应加浅底或白底
- 避免文字直接压在线上
- 多条箭头靠近时，标签要错位

## 5. 避免穿节点

- 箭头应尽量从边缘锚点连出
- 不要从几何中心硬穿整个节点
- 复杂图优先用折线或走廊线

## 6. 大图也要有主干

- 即使节点很多，也要让人先看到主线
- 旁支和补充关系降权处理

## 7. 适合模板化的字段

以下结构最适合模板生成：

- `title`
- `subtitle`
- `style`
- `containers`
- `nodes`
- `arrows`
- `legend`
- `style_overrides`
