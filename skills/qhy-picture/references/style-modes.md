# qhy-picture 扩展视觉模式

仅在个人 IP、实物微型人涂鸦、CRT 叙事或 3:4 IP 信息图模式中读取本文件。

## 个人 IP 角色系统

### 身份锚点

仅记录可见或用户确认的发型与发色、脸部结构、眼睛、肤色、招牌表情、服装、鞋、配件、轮廓、比例和招牌色。将它们分为“永不改变”和“可按场景变化”。参考冲突时优先最新明确要求，否则保留重复出现的特征。

初次建立 IP 时生成：

1. 一张 1:1 正面全身角色锚点图。
2. 一张横向正面/侧面/背面转面图。

各视图保持服装、颜色、配件、轮廓和比例一致；不要自动添加方向标签。

### 标记与色彩锁

- 小角色或小场景默认占画布 20%–35%，周围保留大量纯白空间。
- 用细到中等粗细的黑色笔线：自然抖动、轻微迟疑、不均匀压力，在发尖、袖口、手、鞋、道具转折处留下不规则短断口。不做统一虚线。
- 色块内部干净平整，但边缘允许轻微短缩、越界或窄白缝，让套色错位在正常观看尺寸可见又不损害识别。
- “限色”表示减少颜色数量，不表示降低饱和度。保留自然肤色、中性黑和清晰招牌色，禁止全局灰棕、米黄、褪色、脏色和复古滤镜。
- 正文稀疏插画默认不含文字、字母、数字、Logo、水印和 UI；用动作、表情和 1–3 个必要道具说清含义。
- 禁止蜡笔、油画棒、粉笔、水彩、干刷、光滑动漫渲染、3D、完美矢量曲线、密集背景和大角色满幅。

### 长文分镜

默认 5 张。先提炼文章主旨、情绪曲线和具体例子，再选择互不重复的视觉节拍。每张必须回答一个准确段落含义，不按自然段机械拆分，不重复“读文件、指图标、站在设备旁”等通用场景。

## 3:4 IP 信息图

仅在明确要求信息图、知识卡、数据卡、流程、时间线、对比或文章总结页时使用。

- 每页承载 4–6 个可读模块。模块过多时增加页数，不缩小文字或塞满画面；最多 8 页。
- 按内容选择总览、流程、时间线、对比、数据故事、案例证据、清单或结论版式。
- 在生成前建立精确文本清单：标题、日期、数量、单位、人名和标签必须来自用户内容，不在图中自动总结或虚构。
- 标题和分区标题用细蜡笔/彩铅式手写痕迹，正文用清楚的黑色记号笔手写感。边框、箭头、下划线和圈注应有不均匀线宽、轻微越角、小断口和二次描线。
- 个人 IP 每页使用 1 个主要姿势或最多 3 个小姿势，占 8%–18%；通过指向趋势、比较选项、检查证据、演示步骤、警告或庆祝帮助理解。
- 图表必须保留用户提供的数值、单位、顺序、尺度方向和来源注记；不发明数据。

## 实物微型人涂鸦

- 保留一个真实拍摄物件的质感，必要时将它从繁杂背景隔离到白或米白空间。
- 使用 1–4 个原始黑线小人，通过搬运、倒入、品尝、攀爬、清洗、维修或探索与物件发生真实空间关系。
- 有字版与无字版必须是两个独立构图。有字版的准确中文优先使用预留标题区+独立标题层；无字版禁止字母、数字和随机字形。
- 不添加喜茶或任何第三方 Logo、官方吉祥物、官方包装标识或联名暗示，除非用户提供已授权资产。

## 复古 CRT 叙事

- 先锁定主体名单、空间关系和每个主体 3–5 个身份锚点。从锚点重新设计，改变原图轮廓、比例和局部细节，不抠图、描边或自动像素化。
- 使用 2–5 色调色板、一个全局方形像素网格、5–9 个主体大色块、直线/阶梯对角线/倒角/楔形语法。脸和暴露皮肤必须是实色块。
- 主体作为无边框壁纸占 60%–80%，用 3–6 个大小不一的早期计算机窗口、1–3 个局部提取窗、一个菜单和一个光标建立层级，保留 20%–30% 连续空场。
- 表面要有硬像素、扫描线、限色辉光、稀疏噪点、短拖影、轻微错位和外侧 10% 桶形弯曲；中心 80% 稳定，不出现物理显示器外壳。
- 不使用上游技能的固定签名；不做现代卡片 UI、玻璃拟态、游戏 HUD、3D、渐变、写实像素肖像或多尺度像素。
