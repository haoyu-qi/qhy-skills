# 观点社论风

适用于融资会记录、长访谈、演讲、播客观点、创始人内部讲话和战略判断。目标不是把原句装饰得更漂亮，而是把分散判断重组为一张可追溯、有立场、有阅读节奏的观点地图。

## 内容重组

### 1. 先建立观点索引

- 保留原始编号或为每条观点补编号。
- 为每条观点标记主题：本质判断、路线、优先级、竞争、资源、组织、价值观。
- 合并同义观点，但在标题或章节标注中保留编号范围，例如 `06—09`。
- 区分原话、压缩转述与编辑结论。材料不是正式逐字稿时，页脚标注“根据材料提炼与重组 · 非逐字稿”。

### 2. 提炼一个主命题

主命题必须能统领全篇，并能形成反差或取舍，例如：

- “产品是台阶，AGI 才是主线”
- “先解决学习，再讨论具身”
- “愿景不是怎么说，而是怎么做”

不要使用“洞察未来”“引领变革”之类空泛标题。标题优先采用原材料中的判断句，并让关键词成为最大视觉锚点。

### 3. 压缩为 3—6 条主线

从下列模块中按内容选择，不要求全部出现：

1. **主命题**：最反常识或最能统领全篇的判断。
2. **路线**：现在 → 突破口 → 加速环 → 终点，用阶梯或时间轴表达。
3. **优先级 / 反命题**：什么排第一，什么重要但不是重点。
4. **竞争判断**：按成本、时间、体验、资源等维度排序。
5. **价值观**：组织方式、利益观、边界与克制。
6. **拉引文**：只保留一条最有张力的句子，不堆金句。

不要把十几条原话机械排成同尺寸卡片。至少同时使用一种流程结构和一种取舍结构，让读者看见“为什么这样排序”。

## 视觉语法

### 色彩

- 纸张底：`#f1eadc`，亮纸：`#fbf7ef`
- 主墨色：`#1d211e`，不可使用纯黑
- 唯一强调色：朱红 `#b53a2e`
- 结构色：墨绿 `#304b3c`
- 阴影使用暖棕染色，不使用默认灰色阴影

朱红负责观点、编号与关键节点；墨绿只用于主命题或路线结构区。不要让两种颜色平均竞争。

### 字体与层级

- 标题和结论：宋体栈，粗重、紧凑，营造社论感。
- 正文和元数据：中文无衬线栈，提高信息密度下的可读性。
- 英文编号可用 Georgia，形成出版物编号感。
- 主锚点 64—110px；章节标题 34—50px；正文 14—17px；元数据 11—13px。

### 构图

- 用 10—12px 顶部重线建立封面感。
- Hero 使用约 3:1 的非对称分栏：左侧主标题，右侧条目总数或期号。
- 章节之间使用满宽细线，不把每个观点包进圆角卡片。
- 交替使用深色块、浅纸张、朱红拉引文制造阅读节奏。
- 路线用横向节点链；优先级用编号表；“重要但非重点”用简短反命题列表。
- 保持方正边界与编辑网格，避免玻璃拟态、霓虹光效、大圆角和三列等宽卡片。

## 标准页面节奏

1. **封面**：来源标签 + 主命题 + 一句解释 + 观点总数。
2. **本质判断**：深色结构区配 2—4 条核心判断。
3. **路线**：4 个以内的阶段链，突出唯一突破口。
4. **取舍**：优先级与“重要但不是重点”形成对照。
5. **宏观判断**：朱红拉引文配竞争维度或资源判断。
6. **价值观收束**：深色底，以 2—4 条行动原则结束。
7. **页脚**：来源、整理性质和逐字稿状态。

内容不足时删减模块，不用空洞文案补齐。内容超过 30 条时先压缩观点，不继续纵向堆叠。

## 移动端

- 在 `768px` 断点把所有分栏折叠为单列。
- 横向路线转为纵向节点链，节点沿左侧轴线排列。
- 标题不得小于 48px，正文不得小于 14px。
- 编号、来源与“非逐字稿”说明不可因折叠被隐藏。

## 自检

- [ ] 能否用一句主命题概括整张卡
- [ ] 原始观点编号是否可追溯
- [ ] 是否形成路线、排序或取舍，而非只有摘要
- [ ] 是否只有一个拉引文和一个主强调色
- [ ] 是否避免等权卡片墙
- [ ] 是否标注材料的逐字稿状态
- [ ] 手机端路线是否转为纵向阅读
