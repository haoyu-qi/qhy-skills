# 视觉方向指南

这里不是主题大全，而是给出足够稳定的推荐映射，帮助快速起手。

## 技术与工程

| 方向名 | 气质 | 适用内容 |
|---|---|---|
| `tokyo-night` | 冷静深色、现代工程感 | 技术分享、基础设施、平台能力 |
| `blueprint` | 蓝图、结构感、工程草图 | 架构图、流程图、系统设计 |
| `terminal-green` | 终端感、等宽字、黑客气质 | CLI、Agent、工具链、demo 风 |
| `engineering-whiteprint` | 白底工程纸、说明书质感 | API、白皮书、架构说明 |

## 商务与正式汇报

| 方向名 | 气质 | 适用内容 |
|---|---|---|
| `corporate-clean` | 稳妥、清爽、正式 | 周报、管理汇报、客户汇报 |
| `pitch-deck-vc` | 白底、留白大、数字优先 | 投资人 pitch、业务方案 |
| `minimal-white` | 极简、克制、不抢内容 | 严肃评审、内部评估 |

## 品牌与内容传播

| 方向名 | 气质 | 适用内容 |
|---|---|---|
| `magazine-bold` | 杂志感、标题强、适合叙事 | 品牌故事、专题内容 |
| `xiaohongshu-white` | 白底图文、中文友好 | 小红书图文、生活方式内容 |
| `soft-pastel` | 柔和、轻松、消费向 | 面向 C 端内容、轻发布 |

## 戏剧化与发布会

| 方向名 | 气质 | 适用内容 |
|---|---|---|
| `cyberpunk-neon` | 高反差、强氛围 | 新品发布、实验性内容 |
| `glassmorphism` | 产品发布会感 | 封面、卖点展示、视觉页 |
| `aurora` | 渐变、氛围感 | 封面、转场页、收尾页 |

## 推荐策略

- 工程受众优先清晰，不优先花哨
- 商务受众优先稳妥，不优先个性
- 社媒受众优先记忆点，不优先信息密度
- 拿不准时，给 2 到 3 个候选：
  - 技术分享：`tokyo-night` / `blueprint` / `corporate-clean`
  - 商务汇报：`corporate-clean` / `pitch-deck-vc` / `minimal-white`
  - 小红书图文：`xiaohongshu-white` / `soft-pastel` / `magazine-bold`

## 避坑

- 不要为了“高级”给严肃汇报强上赛博霓虹
- 不要给信息密集页用过强背景纹理
- 不要整份 deck 每一页都高饱和
