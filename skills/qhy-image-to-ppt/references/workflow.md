# 布局清单与裁切

复杂页面先在工作目录保存逐字稿与结构清单。不要把当前业务截图或文本加入技能安装包。

```json
{
  "canvas": {"width": 1672, "height": 941},
  "regions": [{
    "id": "page-01-module-a",
    "box": [285, 265, 347, 106],
    "objects": [
      {"id": "title", "kind": "native-text", "text": "原图标题", "box": [384, 272, 239, 30]},
      {"id": "icon", "kind": "image-crop", "assetId": "icon-a", "targetBox": [303, 281, 55, 53]}
    ]
  }]
}
```

源图裁切框为原图整数像素 `[x,y,width,height]`，目标摆放框为幻灯片坐标。原图、放大预览和目标画布的坐标不能混用。

## 裁切工具

清单示例：

```json
{"crops": [
  {"id": "page-01-icon-a", "box": [303, 281, 55, 53]},
  {"id": "page-01-photo", "box": [770, 705, 91, 47]}
]}
```

```bash
python scripts/prepare_assets.py --source /path/source.png --manifest /path/crops.json --output-dir /path/work/assets/page-01
```

脚本保留原像素无损裁切，不放大，默认拒绝覆盖；确认要更新工作素材时使用 `--overwrite`。输出 `assets.json` 记录源哈希、尺寸和裁切框。脚本不自动判断图片里有没有旧字，仍需打开素材检查。

## 已观察到的故障

| 现象 | 先检查 | 修复 |
|---|---|---|
| 字体有第二道边、加粗得不自然 | 带字整页底图或裁切里的旧字 | 去掉整页底图，重新裁切与重建容器 |
| 文本移动后露字 | 遮罩没移动或覆盖不完整 | 去除含字背景；必要时分组遮罩和对象 |
| 图标像残缺文字/淡色竖条 | 误裁文字区、源框与目标框混用 | 放大源图重新定位图标，分别记录两种框 |
| 图标丢失或图层顺序随机 | 图片处理 Promise 未等待 | 资产处理全部完成，再按确定顺序加入对象 |
| 标题碰到右侧短句 | 文字实际宽度超出标题区 | 给双方独立空间，调整字号或局部布局 |
| 正文压到下一张卡 | 显式换行叠加自动换行增加行数 | 调整宽高和断行，不通过删原文解决 |
| 中心标题压在台座上 | 图层与对比度，不只文本框 | 调整台座位置、前后顺序与文字留白 |
| 流程关系改变 | 箭头被当装饰处理 | 核对端点、方向、汇合关系及标签 |

逐字稿应独立于布局代码，调整断行不改写正文。复杂产品 UI 内的字随图保留时标记 `raster-with-text`，不叠第二份文字；若用户要求这些字也能编辑，就进一步分解，不用不可见文本层冒充可编辑。
