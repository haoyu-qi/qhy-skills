# qhy-ppt 结构规则

先判断用户需要的是“讲清楚”还是“讲服别人”，再确定 deck 结构。

## 1. 结构优先于文案

- 先列页面角色，再写页面内容
- 一套 deck 最好能用一句话解释它的推进逻辑
- 如果推进逻辑说不清，说明结构还没定下来

## 2. 常用推进逻辑

### 结论驱动

适合汇报、老板同步、决策沟通。

顺序：

1. 结论
2. 为什么得出这个结论
3. 证据和拆解
4. 风险与下一步

### 问题驱动

适合方案、提案、优化建议。

顺序：

1. 现状问题
2. 目标
3. 方案
4. 预期收益
5. 推进计划

### 教学驱动

适合培训、说明、方法传递。

顺序：

1. 先告诉对方学完能获得什么
2. 再给总框架
3. 然后分步展开
4. 最后给示例和避坑点

## 3. 页数建议

- 5 页以内：只保留结论、背景、关键证据、下一步
- 6-10 页：适合常规汇报和方案沟通
- 10-20 页：适合培训、路演、复杂方案

页数不够时优先砍“重复解释”，不要砍“结论和关键证据”。
