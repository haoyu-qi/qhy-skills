# qhy-ppt 表达风格

## 1. 面向中文汇报语境

- 少用英文咨询腔套话
- 多用“结论、原因、动作、影响”这种清晰句法
- 可以专业，但不要故作玄虚

## 2. 标题写法

优先：

- 当前方案更适合先在华东试点
- 这个季度项目进度整体达标，但测试环节拖慢上线
- 我们建议把资源集中到转化率最高的两个渠道

避免：

- 项目进展
- 情况说明
- 相关分析

## 3. 页面语气

- 对老板：直接、判断明确、少铺垫
- 对客户：价值导向、可信、不过度内部化
- 对团队：信息透明、动作具体、风险说清

## 4. 视觉倾向建议

- 汇报型：克制、清晰、优先信息层次
- 路演型：记忆点更强，开场与收尾更有张力
- 培训型：示例和步骤感强，减少花哨装饰
