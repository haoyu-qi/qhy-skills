# qhy-word 文档模式

## 1. 方案文

常见结构：

1. 背景与目标
2. 当前问题
3. 方案设计
4. 推进计划
5. 风险与资源需求

适合要推动决策和落地的文档。

## 2. 报告文

常见结构：

1. 核心结论
2. 关键事实
3. 分析拆解
4. 问题与判断
5. 建议动作

适合汇报和总结。

## 3. 说明文

常见结构：

1. 定义与适用范围
2. 规则说明
3. 操作步骤
4. 注意事项
5. 附录

适合制度、流程、产品使用说明。

## 4. 纪要文

常见结构：

1. 会议主题与背景
2. 关键结论
3. 讨论要点
4. 待办事项
5. 责任人与时间点

纪要不是聊天记录整理，而是会后协作的起点。
