# qhy-card

一个面向中文内容可视化的 HTML 铸卡技能。它吸收了“内容决定构图”的方法，但保持零外部依赖、可直接编辑和离线预览的 HTML 输出路线。

## 核心原则

1. 形式服务于内容，不为套模板而套模板。
2. 模具决定画面类型，风格决定气质，内容密度决定布局。
3. 输出必须能直接保存为单文件 HTML 并离线打开。
4. 默认优先由模型根据内容自主选择风格；当用户想参与审美决策时，再进入交互式风格选择。

## 执行顺序

生成前必须按顺序读取：

1. `references/taste.md`
2. 对应模具说明
3. 对应风格参考
4. 对应模板骨架

## 风格选择策略

### 默认模式：模型自主选择

- 当用户没有指定风格时，模型必须根据内容主题、信息密度、语气和使用场景自动匹配风格
- 自动匹配后直接生成，不需要为了风格问题额外打断用户
- 若内容横跨多个风格边界，优先选择更有助于信息表达的风格，而不是更“花哨”的风格

### 交互模式：引导用户选择

在以下情况可以引导用户参与风格选择：

- 用户明确说“你帮我选几个风格让我挑”
- 用户对视觉气质有要求，但描述仍然模糊
- 内容适合至少两种截然不同的表现路线，比如“深度报道”与“发布海报”都说得通

此时应提供 2 到 4 个清晰选项，每个选项附一句适用说明，帮助用户快速决定，而不是把全部风格列表生硬甩给用户。

## 内容分析规则

在开始写 HTML 前，先完成这些判断：

- 标题：一句话，能直接做主视觉
- 副标题：解释标题，不复述标题
- 来源：作者、团队、日期、文档名、会议名等
- 密度：稀 / 中 / 密
- 结构：单点 / 对比 / 层级 / 流程 / 辐射 / 并列
- 重点：哪一个元素必须成为画面中的最大锚点

## 用户指令映射

| 用户描述 | 处理方式 |
|---------|---------|
| 宽一点、宽屏 | 容器宽度提升到 1200-1440px |
| 竖版、窄一点 | 单列优先，减少横向分栏 |
| 简洁、极简 | 减少卡片数，放大标题和留白 |
| 信息密集、干货 | 增加注释、编号、对比表和标注层 |
| 暗色 | 优先暗黑科技风 |
| 浅色、亮色 | 优先扁平现代风或纯白演示风 |
| 你来决定、自动选风格 | 启用模型自主风格判断 |
| 给我几个风格选项、让我挑风格 | 进入交互式风格引导，给出 2 到 4 个候选 |
| 手绘、白板 | 优先 `-w` 白板图 |
| 海报、封面 | 优先 `-p` 海报页 |
| 周报、月报、复盘 | 优先 `-r` 周报板 |
| 无需注释 | 不输出任何 HTML 注释 |

## 输出规范

### 必须做

- 直接输出完整 HTML
- 所有 CSS 内联到 `<style>` 中
- 包含 `<meta charset="UTF-8">` 和 viewport
- 添加移动端断点 `@media (max-width: 768px)`
- 保证中文场景可读性
- 用非对称布局建立节奏，不默认三等分

### 禁止做

- 禁止引入外部 CSS/JS
- 禁止依赖远程图片或字体
- 禁止使用纯黑 `#000000`
- 禁止出现 AI 套壳味很重的居中 Hero + 三栏卡片默认布局
- 禁止让所有模块同尺寸同权重
