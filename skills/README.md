# Skills Directory

这里存放 `qhy-skills` 仓库中的所有技能。

## 当前技能

- `qhy-card`：HTML 视觉卡片生成
- `qhy-ppt`：演示文稿结构与逐页表达
- `qhy-draw`：draw.io 图表生成与导出
- `qhy-word`：正式文档写作与整理
- `qhy-humanizer-zh`：中文文本去 AI 味与自然化改写
- `qhy-avcon-zentao-iteration`：AVCON/QHY 禅道软件迭代任务模板，支持 5 阶段一级任务和基于需求文档的子任务拆解

## 推荐分工

- `qhy-card`：适合看板、卡片、封面、信息图
- `qhy-ppt`：适合汇报、提案、培训、路演
- `qhy-draw`：适合流程图、架构图、UML、ER 图、思维导图、网络拓扑图
- `qhy-word`：适合方案、报告、纪要、说明文
- `qhy-humanizer-zh`：适合文章、文案、报告段落、对外说明
- `qhy-avcon-zentao-iteration`：适合禅道软件迭代、阶段任务、需求文档拆子任务

## 新增技能建议

1. 复制 `skills/_template/`
2. 将目录重命名为 `skills/qhy-<name>/`
3. 修改 `SKILL.md`
4. 按需补充 `references/`、`assets/`、`scripts/`
5. 更新仓库根目录 `README.md` 中的技能总览

## 命名约定

- 统一使用 `qhy-*`
- 技能名尽量表达能力，而不是表达实现方式
- 避免一个技能承担过多互不相关的职责
