# Examples

这里收录 `qhy-skills` 仓库中的代表性示例输出，方便快速预览整体风格和交付形态。

## 当前示例

| File | Skill | 类型 | 说明 |
|---|---|---|---|
| `qhy-card-priority-board.html` | `qhy-card` | 周报板 / 看板 | 适合项目优先级、推进状态、任务分层展示 |
| `qhy-card-priority-deck.html` | `qhy-card` | 信息图 / 汇报页 | 适合把项目重点整理成一页式汇报视觉稿 |
| `qhy-card-ai-roadmap-board.html` | `qhy-card` | 路线图 / 白板板式 | 适合 AI 规划、阶段里程碑和模块关系表达 |

## 怎么使用这些示例

1. 先看文件名，判断它更接近哪类表达任务。
2. 用浏览器直接打开 HTML，观察版式、信息密度和模块组织。
3. 借鉴结构和节奏，不要机械复制具体文案。

## 补充示例时建议

- 文件名里带上 skill 名和内容主题
- 优先放真实任务改写后的示例，不要只放占位页
- 一个示例尽量只突出一个主要模式或风格方向
- 若示例依赖特定 skill 规则，记得同步更新对应 `SKILL.md`
