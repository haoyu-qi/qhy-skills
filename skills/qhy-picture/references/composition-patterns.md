# 构图模式与原创规则

## 选择一种叙事结构

### 动画工作台

适合解释工具、方法、判断和输出之间的关系。让人物在桌面或控制台上操作一个关键部件，不要画整套系统架构。

### 转换机器

适合表达升级、封装、提炼和从一次性到可复用。输入和输出都要少，人物负责启动或调节变化。

### 包装与适配

适合表达标准、兼容、交付、迁移和格式转换。用箱子、锁扣、插头或适配器形成动作，不要画产品 Logo 墙。

### 判断装置

适合表达定义、取舍、验收、优先级和反馈。可使用秤、仪表、闸门或测量工具，让人物亲自调整标准。

### 前后场景

适合混乱到有序、重复劳动到可复用、孤立到连接。使用一个连续空间或镜头转场，避免僵硬的左右对照表。

### 路径冒险

适合成长路线、能力积累和工作方法迁移。节点控制在 3-5 个，人物必须正在走、搭桥、转向或排除障碍。

### 小型动画分镜

适合失败、发现、调整、完成等连续状态。最多 2-4 格，每格只保留一个动作和一个短标注。

## 原创隐喻方法

1. 把抽象概念改写成物理动作：组装、压缩、解锁、适配、称量、翻译、回流、折叠。
2. 选择一个容易看懂的生活化物件：工作台、行李箱、旧机器、工具车、刻度盘、桥、邮局、厨房器具。
3. 让人物执行动作，并让动作直接导致文章结论。
4. 删除不影响核心关系的节点、装饰和箭头。

## 反复刻规则

`assets/examples/` 只用于色彩、笔触、人物成熟度和信息密度校准。不要默认复刻以下已用隐喻：

- 把 Skills 与 MCP 送入手摇包装机
- 巨型机械臂配合判断旋钮
- 用压面机把 Prompt 压成能力包
- 两个不同锁扣的包装盒与适配钥匙
- 用天平表示“解决什么”和“怎样算完成”

同类主题必须重新选择物件、动作、视角或空间关系。
