# qhy-photo

把照片当作现场证据，而不是等待套滤镜的素材。先读取主体、空间、方向、色彩、动作、留白和情绪，再选择一条明确的创作路径。

## 请求路由

1. **照片编辑 / Photo Editorial**：保留照片本身，辅以简洁标题或照片派生的抽象记忆面板。
2. **实景拼贴 / Gathered Scene**：保留现场身份，允许照片、抽象形状、线描和手撕边界共同构图。
3. **场景蒸馏 / Scene Distillation**：不保留原照片，只提取事实、关系与情绪，重新创作独立插画或海报。
4. **极简纸刊海报 / Minimal Zine Poster**：从主题、句子、文章、物件或情绪中提炼一个视觉隐喻。
5. **参考分析 / Reference Analysis**：提取固定规则、可变规则和样本残留，不复制原文、品牌、人物身份、精确构图或水印。
6. **批量变体 / Batch Variations**：保持材质、情绪和色彩系统统一，但改变版式家族、锚点形式和文字分布。
7. **实物微型人涂鸦 / Object + Micro Doodle**：保留一个真实物件，用粗拙黑线小人与它发生搬运、清洗、攀爬、探索等动作；可做粗糙手写标题版或纯画面版。
8. **照片复活 / Photo Revival**：保留主体、环境和 1–2 个记忆点，在大面积白纸上重画为小尺度、局部鲜色的诗性插画。
9. **复古 CRT 界面 / CRT Editorial**：仅在明确要求像素、老电脑、CRT、Macintosh 或 Minitel 风格时使用；将主体重构为独立的低面数像素编辑插画。

若用户只说“用这张图做一张”，将照片判定为高保真编辑目标。若说“参考这张图的风格”，判定为低保真参考图。若说“把照片里的某人/物放进去”，判定为支持性插入。只有两种路径会造成明显不同结果时才询问。

使用第 7–9 条路径前读取 `references/style-recipes.md`。

## 统一工作流

### 1. 阅读现场

检查每张输入图，记录可见事实：尺寸与比例、主体、主体关系、前后景、方向轴、尺度、间隔、重叠、光线、主要色彩、空白、动作和情绪。不凭空补写地点、日期、品牌或身份。

将照片事实分为：

- **必须保留**：用户点名的主体、关系、身份、产品几何、建筑关键轮廓等不可替代事实。
- **可变换**：裁切、缩放、版面位置、纸张、抽象程度、周围留白、标题和印刷处理。
- **禁止新增**：无法从照片或用户要求追溯的人物、物件、符号、品牌和装饰。

### 2. 选择保真度

- **High**：保留人物/宠物/产品/艺术品的身份、面部结构、比例、姿态、标志性细节、数量和主要颜色。优先使用原图裁切、剪贴或印刷片段。
- **Medium**：保留主要主体与识别特征，可改变裁切、大小、色调、表面处理和周围构图。
- **Low**：只保留视觉语法、关系、颜色和情绪，不保留源主体或精确构图。

### 3. 提炼核心关系

只选一个可视化关系，例如人与远方、窗与光、道路与方向、两个几乎接触的碎片、被打断的线、重复形态中缺失的一项或孤立于原语境的物件。

### 4. 选择版式与材料

默认竖版 3:5，保持 70%–90% 开放留白，主视觉事件占 8%–25%。从版式、锚点、文字、质感和色彩五个轴中各选一项；默认只用一个明确的高纯度主色，辅色最多微量。

### 5. 编译生图提示词

写成四个紧凑段落：

1. 画布比例、材料、边框、留白比例、主视觉位置与大小。
2. 输入照片的角色与保留契约；核心关系、锚点形式、允许改变和可新增内容。
3. 短标题、字体气质、主色的具体色相与承载形式、印刷或平面处理。
4. 光线、对比度、情绪和最相关的禁止项。

照片编辑路径必须写明“保留什么、允许改什么、只可新增什么”。参考图路径必须写明“不保留源主体、文字、品牌和精确构图”。

### 6. 生成与检查

照片是编辑目标或支持性插入时，实际传入目标图；参考图只用于分析视觉规则。生成后检查完整图和缩略图：

- 真实照片或主体是否仍可辨认，人物/产品/建筑的关键事实是否漂移。
- 作品是否落入广告、产品 mockup、现成模板、电影海报或密集拼贴。
- 留白、单一视觉事件和主色锚点是否成立。
- 重要形状、颜色、方向和层级是否可追溯到照片事实。
- 是否出现额外人物、物件、图标、Logo、水印、CTA、霓虹、3D、硬阴影或多色混乱。

若高保真目标不可辨认，收紧不变量、减少允许变化后最多重新生成一次；仍失败时说明保真限制。

## 路径专用规则

### Photo Editorial

- 照片置于上方或主要区域，只允许比例缩放和轻微裁切；不重画、扩展、替换、滤镜化或修饰内容。
- 下方使用平整连续的中性象牙色面板，抽象元素只来自照片的空间、色调、颜色、方向、尺度、节奏或重叠关系。
- 只用一个主标记家族和最多两个辅助家族。标题仅放在抽象面板，原创英文 2–5 词。
- 人物可抽象为不规则连续短竖线或轻微收尖块，不绘制脸、四肢或衣服；地标建筑最多保留 1–3 个识别线索。

### Gathered Scene

- 真实照片是不可替代的现场锚点；抽象插画延展空间，不负责描摹全部细节。
- 让照片、抽象形状、结构性色彩、少量线描、短标题和手撕纤维边界形成清楚观看路径。
- 不使用厚重 mockup、相框、胶带或阴影制造立体展示效果。

### Scene Distillation

- 成品不保留原照片；先提取事实、命题、张力和情绪，再重新创作。
- 只使用一个核心隐喻、一个主要动作/关系、一个高纯度色彩结构和大面积留白。
- 可重组轮廓、路径、光影和颜色，但不误称为原照片的真实还原。

## 扩展配方的共同规则

- 实物涂鸦保留真实物件，只把小人、动作线和标题作为增量层。
- 照片复活是“可识别的重画”，不是高保真编辑；默认主视觉占画布 10%–18%，空白不少于 80%。
- CRT 路径先锁定主体名单和身份锚点，再主动改变原图轮廓、比例和局部细节；不将抠图、描边或自动像素化当作创作。
- 不使用上游技能的固定签名、品牌 Logo、官方包装、水印、私有参考素材或原文案；用户明确提供且拥有授权的素材除外。

## 禁止方向

full-bleed 场景、商业广告标题层级、产品广告、Logo、CTA、品牌活动视觉、光泽 mockup、干净 UI 白、电影光、硬阴影、景深、3D、霓虹、赛博朋克、密集 scrapbook、多色模板、股票照片质感、长段落可读文字、复制参考图文字或构图、虚构地点日期和水印。CRT 和实物涂鸦路径的明确规则优先于本段中与其冲突的默认禁止项。

## 输出格式

- **生成类**：输出生成图片；必要时附最终 Prompt、路径/Recipe 和一句说明。Photo Editorial 默认只回成品图。
- **分析类**：返回风格名称、一句话定义、观察证据、固定系统、可变系统、样本残留、可复用 Prompt、随机化区块、避免项、置信度与限制。
- **Prompt-only**：只返四段 Prompt、选定 Recipe 和必要禁止项，不暗示已生成图片。

## 来源与使用边界

本 skill 对以下公开项目的方法进行独立中文化重构，不逐字复制其文档、Prompt 或示例素材：

- `gc-minimal-zine-poster`：留白纸刊海报、照片角色判定、参考分析、变体与质量门。
- `photo-abstract-editorial`：原图保真、照片派生抽象面板、平整象牙色面板和短英文标题。
- `gathered-scenes-zine-skill`：实景拼贴与场景蒸馏。
- `heytea-style`：真实物件、粗拙黑线微型人和有字/无字两条海报路径；只吸收通用视觉语法，不复制品牌资产。
- `photo-revival`：照片可识别重画、小尺度局部鲜色与 80% 以上白纸留白。
- `tait-crt-interface-skill`：独立重构的 1980s 像素编辑插画、早期计算机窗口、限制调色板、统一像素网格和 CRT 信号表面。

`gc-minimal-zine-poster` 与 `photo-revival` 为 MIT；`photo-abstract-editorial` 仅授权个人学习、研究与非商业用途，商用需事先授权；`heytea-style` 与 `tait-crt-interface-skill` 的公开页面未标注标准开源许可证。涉及公开发布、客户项目、收费生成、商业服务或二次分发时，优先使用独立改造的视觉语法，并核对原仓库当前许可条款。
