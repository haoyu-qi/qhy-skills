# qhy-photo 扩展风格配方

仅在 `SKILL.md` 路由到实物微型人涂鸦、照片复活、CRT 编辑或影像—插画双联时读取本文件。这些是独立重构后的通用方法，不是品牌模板或上游 Prompt 副本。

## 实物微型人涂鸦

1. 选择照片中轮廓最清楚、情感联想最强的一个真实物件；繁杂背景先裁切或隔离为白场。
2. 保留物件的摄影质感，不把整张照片卡通化。增加 1–4 个原始黑线小人，让它们通过攀爬、搬运、品尝、清洗、维修或探索说清一个小故事。
3. 有字版以粗糙、歪斜、儿童记号笔感的短中文为第一信号；无字版禁止文字、字母、数字和随机符号。两版同时生成时使用独立构图。
4. 准确中文需要可发布时，先生成预留标题区的底图，再生成或排版独立标题层。
5. 默认 3:4 或 2:3 竖版、白或柔和米白背景、大量留白。禁止光滑矢量、贴纸风、漫画分镜、渐变、密集装饰和写实人脸。

## 照片复活

1. 记录主体、场景与 1–2 个最有记忆度的细节，将它们作为可识别契约；其余信息主动删减。
2. 在白或极浅纸面上重画，不套滤镜、不做写实修图、不拷贝照片的全部轮廓。
3. 默认 3:4 竖版，主体或聚簇占 10%–16%，不超过 18%；留白 80%–88%。
4. 铅笔边缘、柔和水彩、笔触或极少量剪贴痕迹只服务主体。最强色彩必须限制在小插画区内。
5. 文字只能是微小的手写日期、注解或诗性短句。

## 复古 CRT 编辑

1. 锁定所有显著或互动主体的数量、前后顺序、相对尺度和关系，每个主体仅保留 3–5 个高信息身份锚点。
2. 从锚点重建独立插画：至少改变一个主要比例、一个主要轮廓和一个结构特征。不得把原照片抠图后像素化、海报化或描边。
3. 用 5–9 个扁平咬合色块构造主体，优先直线、阶梯对角线、倒角、楔形和低边数多边形；曲线仅在身份识别必需时保留 1–2 条粗阶梯弧。
4. 使用 2–5 色限制调色板和一个全局方形像素网格。棋盘网点只可用于非皮肤的局部中间调，脸、手和暴露皮肤使用实色块。
5. 主体作为无边框壁纸占 60%–80%；叠加 3–6 个大小不一的早期计算机窗口、1–3 个不同比例的局部提取窗、一个菜单和一个光标，同时保留 20%–30% 连续空场。
6. 表面必须可见硬像素、扫描线、调色板内辉光、稀疏噪点、短暂拖影、轻微像素错位和外侧 10% 的桶形弯曲；中心 80% 保持稳定，不绘制物理显示器外壳。
7. 禁止写实像素肖像、现代卡片 UI、玻璃拟态、游戏 HUD、3D、渐变、多尺度像素与上游固定签名。

## 影像—插画双联：复古稚拙手绘

1. 将下半区视为独立的手绘编辑插画：提炼上方最有识别度的主体、轮廓、姿态和叙事关系，以概括造型、适度比例夸张、符号化特征和幽默隐喻重构，但保持一眼可辨。
2. 形体简练，轮廓允许迟疑、轻微歪斜和手工误差；可放大 1–2 个高信息特征。气质在现代主义编辑插画、包豪斯平面构成、儿童绘本、稚拙艺术与时尚速写之间，不变成可爱卡通或光滑矢量。
3. 从上方照片取样 3–5 色：高明度、低至中等饱和度，以近似色统一，只用小面积互补色作跳点。
4. 混合水彩、水粉、彩铅、粉蜡笔和干刷的视觉痕迹，保留纸粒、透底、断笔、毛边、轻微脏色和旧印刷套色偏差。背景以米白或浅色大留白为主，只用松散淡彩、局部斜线或简单几何承托。
5. 可使用少量英文关键词、短标题、编号或原创短句。主标题用稚拙、复古的手写艺术字，辅文字用克制温和的无衬线或衬线；允许轻微错位、倾斜、拉长、叠色或套印偏移，但不得喧宾夺主。
6. 目标气质是轻松、俏皮、复古、温柔、聪明、时髦、幽默、浪漫与松弛，带一点笨拙和古怪自信。禁止复杂场景堆积、写实光影、3D 渲染、过度精修和商业广告层级。

## 影像—插画双联：公共议题观念线条

1. 下半区只用一组连续的黑色手绘线条表达原图的方向、连接、矛盾、压力与转机；线条可像被拉紧的细铁丝、路径、束缚或伤口，但不做直白说明图。
2. 让线条从画面边缘进入，在下方盘绕、交错、回折、收紧，再向上或向外抬升。与原主体相关的象征轮廓应在运动中自然显露，可不封闭、不完整，但必须一眼可感。
3. 使用冷白、米白或低饱和浅色底与大面积留白。主体偏下、偏侧或靠边，不居中、不铺满。黑线粗细略变，保留摩擦、迟疑、断裂和压力感。
4. 尖刺、结点、倒钩或短横只出现在受力、交叉或改变方向的位置。意义应从缠绕、限制、穿越、收紧与释放之间逐渐显现，整体安静而紧张。
5. 文字最多是一个英文主题词、编号、已知地点或一句原创短句，以纤细、克制、略带手工感的形式嵌入空白或线条转折；不成为中心，不直接解释主题。
6. 禁止复杂场景、写实光影、三维质感、多色填充、卡通感、商业广告感、装饰性曲线和无意义的视觉丰富。

## 共同质量门

- 缩略图中能否立即看到唯一视觉事件。
- 原图事实、允许变化和新增元素是否分开。
- 人物、宠物、产品和地标的保真契约是否满足。
- 是否滑向广告、现成模板、全景描摔、品牌仿制或纯滤镜。
- 双联海报是否每张原图独立输出、画布为 3:4、分区为精确 1:1，上半保真且下半可追溯。
