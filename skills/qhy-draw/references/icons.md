# qhy-draw 图标参考

## 兼容性规则

- 不要依赖远程图标字体
- 不要使用在线 `@import`
- 优先用基础 SVG 形状拼图标
- 图标只是辅助识别，不能替代标签

## 常见语义与推荐形状

| 语义 | 推荐形状 |
|---|---|
| User / Human | 圆形头像或简化人形 |
| LLM / Model | 双边框矩形或强调色圆角矩形 |
| Agent | 六边形或双边框控制块 |
| API / Gateway | 六边形 |
| Tool | 扳手 / 齿轮语义矩形 |
| Browser / UI | 带顶部条的窗口矩形 |
| Vector Store | 圆柱 + 横向分层线 |
| Graph DB | 圆点簇或连接点群 |
| Document | 折角文档形 |
| Queue / Stream | 管道或长条通道 |

## 使用规则

- 同一张图中，相同语义保持一致
- 不要为了“产品图标化”破坏结构一致性
- 如果没有把握，优先退回到清晰标签和标准形状
