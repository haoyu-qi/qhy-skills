# qhy-photo

把照片当作现场证据，而不是等待套滤镜的素材。先阅读主体、空间、方向、色彩、动作、留白和情绪，再选择最小而明确的创作路径，输出一张完成度高、可解释、不过度商业化的平面作品。

## 请求路由

选择能满足请求的最小路径：

1. **照片编辑 / Photo Editorial**：用户要保留照片本身。原图作为主要区域，辅以简洁标题或下方的照片派生抽象面板。
2. **实景拼贴 / Gathered Scene**：用户要保留现场身份，同时允许照片、抽象形状、结构性色彩、线描和手撕边界共同构图。
3. **场景蒸馏 / Scene Distillation**：用户明确要求“不保留原照片”“重新创作”或“提炼情绪”。照片只提供事实、关系和情绪来源，成品是独立的纸面插画或编辑海报。
4. **极简纸刊海报 / Minimal Zine Poster**：没有照片或用户只给主题、句子、文章、物件或情绪时，提炼一个视觉隐喻，制作留白纸感海报。
5. **参考分析 / Reference Analysis**：用户给出参考图并要求分析或仿制视觉系统。只提取固定规则、可变规则和样本残留，不复制原文、品牌、人物身份、精确构图或水印。
6. **批量变体 / Batch Variations**：同一主题做多张时，保持纸面、留白、印刷感和克制情绪统一，但相邻作品必须改变版式家族、锚点形式和文字分布。

若用户只说“用这张图做一张”，默认将照片判定为高保真编辑目标；若要求“参考这张图的风格”，判定为低保真参考图；若说“把照片里的某人/物放进去”，判定为支持性插入。只有两种路径会造成明显不同结果时才询问。

## 统一工作流

### 1. 阅读现场

检查每张输入图，记录可见事实：尺寸与比例、主体、主体之间的关系、前后景、方向轴、尺度、间隔、重叠、光线、主要色彩、空白区域、动作和情绪。不要凭空补写看不见的地点、日期、品牌或身份。

将照片事实分成三类：

- **必须保留**：用户点名的主体、关系、身份、服装、产品几何、建筑关键轮廓或其他不可替代事实。
- **可变换**：裁切、缩放、版面位置、纸张、抽象程度、周围留白、标题和印刷处理。
- **禁止新增**：无法从照片或用户要求追溯的新人物、新物件、新符号、品牌和装饰。

### 2. 选择保真度

- **High**：保留人物/宠物/产品/艺术品的身份、面部结构、比例、姿态、标志性细节、数量和主要颜色。优先使用原图裁切、剪贴或印刷片段，不把真实主体重画成模糊插画。
- **Medium**：保留主要主体与识别特征，可改变裁切、大小、色调、表面处理和周围构图。
- **Low**：只保留视觉语法、关系、颜色和情绪，不保留源主体或精确构图。

### 3. 提炼一个核心关系

不要把整张照片逐项说明。选择一个可视化关系，例如：人物与远方、窗与光、道路与方向、植物与空白、两个几乎接触的碎片、一个被打断的线、一组重复形态中缺失的一项、或孤立于原语境的物件。

### 4. 选择版式与材料

默认竖版 3:5；除非用户指定，保持 70%–90% 的开放留白，主视觉事件约占 8%–25%。可从以下轴各选一种：

- 版式：中心碎片、左下漂浮、右上色块、双面板、不规则剪纸、文字主导、点线环绕、单一标本、对角笔记、边缘配重。
- 锚点：真实照片裁切、撕纸照片、扁平轮廓、印刷色块、旧插画、物件标本、半透明几何、抽象纹理窗、碎片化文字。
- 文字：短标题压在图像边缘、档案微文本、斜向散字、灰色幽灵字、粗糙凸版标题、色块内文字、几乎无字的小注。
- 质感：温暖纸纤维、复印柔化、孔版印刷颗粒、凸版油墨溢出、半色调、扫描噪声、轻微套印错位。若使用 Photo Editorial 的下方面板，则改用平整无纹理象牙色，不要把纸张噪声强加进去。
- 色彩：一个明确的高纯度主色作为视觉锚点，辅色最多微量；主色应在缩略图中可见，不要被“低饱和、褪色、粉彩”削弱。

### 5. 编译生图提示词

按以下顺序写成 4 个紧凑段落，不要只堆砌风格形容词：

1. 画布比例、纸面/面板、边框与留白比例、主视觉位置和大小。
2. 输入照片的角色与保留合同；核心关系、锚点形式、允许改变的内容和新增元素。
3. 短标题、字体气质、主色的具体色相与承载形式、印刷或平面处理。
4. 光线、对比度、情绪和最相关的禁止项。

照片编辑路径必须明确写出“保留什么、允许改什么、只可新增什么”。参考图路径必须明确写出“不保留源主体、文字、品牌和精确构图”。

### 6. 生成与检查

调用内置图像生成能力时，照片是编辑目标或支持性插入，就实际传入目标图；参考图只用于分析视觉规则。生成后检查完整图和缩略图：

- 真实照片是否仍可辨认，人物/产品/建筑的关键事实是否漂移；
- 作品是否是平面编辑页，而非广告、产品 mockup、电影海报或密集拼贴；
- 留白、单一视觉事件和主色锚点是否成立；
- 抽象面板中的每个重要形状、颜色、方向和层级是否能追溯到照片事实；
- 标题是否短、克制且没有伪造品牌、日期、地点或长段落；
- 是否出现额外人物、物件、图标、logo、水印、CTA、霓虹、3D、硬阴影或多色混乱。

若高保真目标不可辨认，收紧不变量、减少允许变化后最多重新生成一次；仍失败时如实说明照片保真限制。

## 三条路径的专用规则

### Photo Editorial：照片 + 抽象记忆面板

- 照片置于上方或主要区域，仅允许比例缩放和为版式所需的轻微裁切；不得重画、扩展、替换、滤镜化或修饰内容。
- 下方使用平整、连续、中性象牙色面板；抽象元素只能来自照片的空间、色调、颜色、方向、尺度、节奏或重叠关系。
- 使用一个主标记家族，最多两个辅助家族；不添加照片中不存在的颜色、符号或装饰。
- 标题只放在抽象面板，原创英文 2–5 词；副标题仅在确有意义时使用。
- 人物可抽象为不规则连续短竖线或轻微收尖块，不绘制脸、四肢或衣服；地标建筑最多保留 1–3 个识别线索。
- 默认输出完成的构图，不额外输出标题候选、分析、日期、logo 或水印。

### Gathered Scene：实景拼贴

- 真实照片是不可替代的现场锚点；抽象插画负责延展照片尚未说完的空间，不负责描摹全部细节。
- 让照片、抽象形状、结构性色彩、少量线描、短标题和可见的手撕纤维边界形成清楚的观看路径。
- 保留用户指定的现场关系，例如人物与海岸线、桥上人群与倒影、建筑塔楼与城市密度；其余内容压缩为少量清楚的形。
- 纸面质感可见，但不使用厚重 mockup、相框、胶带或阴影制造立体展示效果。

### Scene Distillation：场景蒸馏

- 成品不保留原照片；先提取事实、命题、张力和情绪，再重新创作独立的纸面插画或编辑海报。
- 使用一个核心隐喻、一个主要动作/关系、一个高纯度色彩结构和大面积留白。
- 可以重组轮廓、路径、光影和颜色，但不得误称为原照片的真实还原。

## 禁止方向

full-bleed 场景、商业广告标题层级、产品广告、logo、CTA、品牌活动视觉、光泽 mockup、干净 UI 白、电影光、硬阴影、景深、3D、霓虹、赛博朋克、可爱卡通、动漫海报、时装大片戏剧感、密集 scrapbook、多色模板、股票照片质感、长段落可读文字、复制参考图文字、复制参考图构图、虚构地点日期和水印。

## 输出格式

### 生成类请求

输出生成图片；必要时附最终 Prompt、路径/Recipe、一句简短说明。若使用照片，附照片角色与保真等级；Photo Editorial 默认只回成品图，除非用户要求解释或 prompt。

### 分析类请求

返回：风格名称、一句话定义、观察证据、固定系统、可变系统、样本残留（不复用）、可复用 Prompt、随机化区块、避免项、置信度与限制。

### Prompt-only 请求

只返回最终四段 Prompt、选定 Recipe 和必要的禁止项，不暗示已经生成图片。

## 来源与使用边界

本 skill 是对以下公开项目能力的重新编排与独立中文化实现，不逐字复制其文档或示例素材：

- `gc-minimal-zine-poster`：留白纸刊海报、照片角色判定、参考分析、变体与质量门。
- `photo-abstract-editorial`：原图保真、照片派生抽象面板、平整象牙色面板和短英文标题。
- `gathered-scenes-zine-skill`：实景拼贴与场景蒸馏两条创作路径，以及“观察现场 → 提取关系 → 重新装订成页”的工作流。

其中第三个仓库 README 标注为个人、非商业使用；第二个仓库 README 标注商业使用需事先授权。涉及公开发布、客户项目、收费生成、商业服务或二次分发时，先取得原作者许可并保留必要署名。
